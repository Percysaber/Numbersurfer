# Number Surfer

เกมวิ่งคิดเลขเร็ว 3 เลน: วิ่งเข้าประตูที่มีคำตอบถูกต้อง ตอบผิดเสียหัวใจ หัวใจหมดจบเกม

## วิธีรัน
    python -m pip install pygame-ce
    python main.py

| ปุ่ม | ทำอะไร |
|---|---|
| 1 / 2 / 3 หรือคลิกปุ่ม | เลือกระดับ Easy / Medium / Hard |
| ← → หรือ A D | เปลี่ยนเลน |
| P หรือ Esc | หยุดชั่วคราว / เล่นต่อ |
| R | เล่นใหม่ (หน้า Game Over) |
| M | กลับเมนู (หน้า Game Over หรือตอนหยุด) |

## กติกา
- ตอบถูก: ได้ 10 คะแนน x ตัวคูณระดับ (1 / 1.5 / 2) x โบนัสคอมโบ (+10% ต่อครั้งที่ถูกติดกัน) และวิ่งเร็วขึ้น
- ตอบผิด: เสียหัวใจ 1 ดวง คอมโบกลับเป็น 0 และแสดงคำตอบที่ถูก
- ตอบถูก 3 ครั้งติดกัน: ได้หัวใจคืน 1 ดวง (สูงสุด 3 ดวง)
- คะแนนสูงสุดของแต่ละระดับบันทึกไว้ใน highscore.json

## ไฟล์และคลาส
| ไฟล์ | คลาส | หน้าที่ | เจ้าของ |
|---|---|---|---|
| main.py | - | 12-step template, อ่าน event แล้วส่งให้ Game | กัปตัน |
| settings.py | - | ค่าคงที่ที่ใช้ร่วมกัน | กัปตัน |
| game.py | Game | state เมนู/เล่น/หยุด/จบ, สร้างโจทย์, ตรวจการชน | กัปตัน |
| player.py | Player (Sprite) | ย้ายเลน + แอนิเมชันวิ่ง | กัปตัน |
| track.py | Track | พื้นทางวิ่ง เส้นประเลื่อน | กัปตัน |
| question_generator.py | QuestionGenerator | สุ่มโจทย์ 3 ระดับ + คำตอบหลอก | ธรรศ |
| gate.py | Gate (Sprite) | ประตูคำตอบหนึ่งบาน | ธรรศ |
| score_manager.py | ScoreManager | คะแนน คอมโบ หัวใจ | ธรรศ |
| high_score.py | HighScore | บันทึก/โหลดคะแนนสูงสุด (JSON) | ธรรศ |
| hud.py | HUD | ป้ายโจทย์ คะแนน หัวใจ ระยะทาง หน้าหยุด/จบเกม | มอร์แกน |
| effects.py | FloatingText, GateFlash, Particle (Sprite) | ข้อความลอย, ประตูเรืองแสง, ประกาย | มอร์แกน |
| sound_manager.py | SoundManager | เพลงและเสียงประกอบ | มอร์แกน |
| menu.py | MenuScreen, Button, MenuSymbol | หน้าเลือกระดับ + คะแนนสูงสุด + แอนิเมชัน | มอร์แกน |

## เสียง
ถ้าเครื่องไม่มีการ์ดเสียง เกมยังเล่นได้ตามปกติ
ปรับความดังได้ที่ `MUSIC_VOLUME` และ `EFFECT_VOLUMES` ใน sound_manager.py
